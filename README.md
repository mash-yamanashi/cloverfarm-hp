## フォルダの中身

```
cloverfarm-hp/
├── index.html   … ページ本体
├── style.css    … デザイン（配色・レイアウト）
├── images/
│   ├── hero.jpg      … トップの写真（現在はロゴ代わりにも使用・仮）
│   └── produce/      … 生産物ごとの写真を入れるフォルダ（現在は空。枠のみ用意済み）
└── README.md
```

## GitHub Pagesでの公開方法（例）

1. GitHubで新しいリポジトリを作成します（個人アカウント配下）。
   - `ユーザー名.github.io` という名前にすると、そのユーザーの公開ルートとして使えます。
   - 別の名前（例：`cloverfarm-hp`）でも公開可能です（URLが `https://ユーザー名.github.io/cloverfarm-hp/` になります）。
2. このフォルダの中身（`index.html` / `style.css` / `images/` フォルダ）をリポジトリ直下にアップロードします。
3. GitHubのリポジトリ画面 → `Settings` → `Pages` を開き、公開元（Branch）を `main`（ルート）に設定します。
4. 数分後、指定のURLでサイトが公開されます。

## 現時点で「仮」になっている部分

- **ロゴ**：正式なロゴが未着手のため、いただいた写真をヘッダーの丸いロゴマークとして仮使用しています。正式ロゴが決まり次第、`images/hero.jpg` を差し替えるだけで反映できます。
- **生産物の写真**：「画像は順次追加していく」とのことでしたので、7品目すべて写真の**枠（プレースホルダー）だけ**を用意しています（「写真準備中」の表示）。写真が届き次第、下記の手順で差し替えてください。

### 生産物の写真の差し替え方

1. 写真を `images/produce/` フォルダに入れます（例：`toumorokoshi.jpg`）。
2. `index.html` 内、該当する `<li class="produce-row">` ブロックの中にある

   ```html
   <div class="produce-placeholder" aria-hidden="true">
     ...
   </div>
   ```

   を削除し、代わりに

   ```html
   <img src="images/produce/toumorokoshi.jpg" alt="とうもろこし">
   ```

   を入れてください。

現在の掲載順は、①とうもろこし ②ヤングコーン ③もも ④すもも ⑤黒ぶどう ⑥シャインマスカット ⑦なす、の順でご指定いただいた通りに並んでいます。

- 生産物ごとの写真が届き次第、上記手順で順次差し替えていきます。
